一、这是什么
    专门用来清除豆包导出图片右下角那行浅灰色「豆包AI生成」字样。
    全程在本机处理，不联网、不上传，原图不会被覆盖。

二、怎么用
    1. 打开「玉用去水印」；
    2. 把图片直接拖进窗口，或点左上角「导入图片 / 导入文件夹」；
    3. 右侧选好强度（默认「强力」）和输出目录；
    4. 点「开始去水印」；
    5. 拖动预览中间的分割线，左右对比处理前后（双击复位、滚轮缩放）。

    快捷键：Ctrl+O 导入 · Ctrl+R 开始 · Ctrl+S 另存 · Delete 移除列表项

三、强度怎么选
    保守 / 轻柔  只剥离高置信的水印笔画，几乎不动原图，适合水印很淡的图；
    标准         日常推荐，兼顾干净与保真；
    强力（默认） 能吃掉肉眼勉强可见的极淡水印，误伤仍然极低；
    极致         水印压在头发、衣褶等复杂内容上时用，剥离最彻底。

    如果自动探测没找到水印（提示"未检测到水印"），先试：
      ① 把「水印位置」手动指定为「右下角（豆包默认）」，再提高一档强度重试；
      ② 还是不行、而你肉眼确实看得到那行字（说明它淡到低于检测下限），用
         「手动框选 + 强制清理」：
           a. 「水印位置」选「手动框选（极淡水印）」；
           b. 在图上按住左键拖一个框，把水印圈住（框上会显示尺寸）；
           c. 勾选「强制清理选中区域」，点「开始去水印」。
         该模式只把**已经接近纸白**的像素抬回局部纸面基准，亮度低的像素权重为 0
         ——也就是说画面里的深色内容（衣服、头发）在数学上就抬不动，不会被误伤。
         代价：框内纸面纹理会被略微抹匀（1~3 灰阶）。

    任务结束后进度条会自动复位；如果一张都没成功，会弹窗告诉你原因并给一键切换。

四、它到底做了什么（为什么不会留下涂抹痕迹）
    1) 检测：以局部背景残差找"比周围暗"的细长笔画，再用"成行排布 + 低对比度 +
       压在亮背景上"三重先验确认是不是水印，避免把头发丝、衣褶当水印抹掉；
    2) 反混合：水印是半透明叠加，按 观测=(1-a)·原图+a·水印色 反解出原图，
       并用引导滤波让系数场贴合字形边缘，笔画内部解出的像素直接就是原图；
    3) 修复：只对"完全被覆盖、反解不可靠"的像素做结构感知填充
       （Telea + Navier-Stokes 双算法融合），再用羽化过渡衔接；
    4) 渲染修复：对被文字压住的纹理按邻域重新生成，保住"原图意愿"。
    因此它是"把被盖住的像素算回来"，而不是拿周围颜色涂一块。

五、设置
    · 开机自动启动：写入注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，
      随时可在界面里关掉；安装时也能勾选。
    · 输出：默认写到"图片\玉用去水印输出"，可改成原图同目录。
    · 支持 PNG / JPG / JPEG / WEBP / BMP / TIFF，保留分辨率与透明通道。

六、卸载
    开始菜单 →「卸载 玉用去水印」，或
    设置 → 应用 → 已安装的应用 → 玉用去水印 → 卸载。
    卸载会自动清理开机自启项。

七、常见问题
    Q: 处理完文件在哪？
    A: 默认在  C:\Users\<你的用户名>\Pictures\玉用去水印输出 ；
       勾了「保存在原图目录」就在原图旁边，文件名带"_已去水印"后缀。
    Q: 会覆盖原图吗？
    A: 不会。原图一律只读。
    Q: 提示"未检测到水印"？
    A: 说明这张图的水印淡到像素级几乎不存在，或位置不是默认的右下角。
       可手动指定位置、提高强度，或换「极致」档。
    Q: 杀毒软件报警？
    A: PyInstaller 打包的程序偶发误报，属正常现象，添加信任即可。
